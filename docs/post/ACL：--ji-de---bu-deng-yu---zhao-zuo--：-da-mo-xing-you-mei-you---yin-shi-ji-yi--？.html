"记得"不等于"照做"：大模型有没有"隐式记忆"？

论文：ImplicitMemBench: Measuring Unconscious Behavioral Adaptation in Large Language Models
作者：Chonghan Qin、Xiachong Feng（通讯作者）、Lingpeng Kong（香港大学），Weitao Ma、Xiaocheng Feng（哈尔滨工业大学）
发表：ACL 2026 长文，第 28232–28261 页，获最佳资源论文奖；arXiv 2026 年 4 月首发
链接：ACL Anthology 页面｜PDF｜arXiv 2604.08064｜代码和数据

一句话版本： 现在测 AI 的记忆，大多是问它"你还记得某件事吗"。这篇换了个问法：经历过的事，会不会自动改变它下一次的做法？ 作者出了 300 道题，考了 17 个模型，最好的 DeepSeek-R1 只有 65.3%，而作者报告人类是 100%。最扎眼的一个对比是：学会"更喜欢做什么"，平均能到 75.0%；学会"别再做什么"，只有 17.6%。

开场：三件你"没想就做了"的事

  • 你会骑自行车，但骑的时候不会去回想"先蹬左脚还是右脚"。
  • 你刚看完一部深海纪录片，朋友让你给新开的咖啡店起个名，你脱口而出"深蓝"。
  • 你在某家餐馆被坑过一次，下次路过，不用想就绕开了。

这三件事有个共同点：你没有刻意去"回想"什么，过去的经验直接变成了行为。 心理学把这叫做隐式记忆。

再想想 AI 助手：

  • 上周你告诉它"我们这个接口的参数顺序是反的"，今天它会不会自己照做？
  • 某个工具连着报错三次，它下次会不会还是第一个去调用这个工具？

这些问题，现有的记忆测试很少问。

这篇论文问的是：大模型能不能把经历过的事，自动地变成下一次的做法？ 它测的不是"记得什么"，而是"自动做了什么"。

第一幕：为什么要测"隐式记忆"

现有的记忆测试在测什么

像 LongMemEval、LoCoMo、MemoryAgentBench 这些常见的记忆测试，基本都是"一问一答"：先给模型一段很长的对话，再问它"用户上个月说过他住在哪？"。这测的是显式记忆，也就是能不能有意识地把事实找出来。

心理学怎么分记忆

作者借用了神经科学家 Squire 的经典分法：

  • 陈述性记忆（显式）：知道"是什么"，比如事实、事件。
  • 非陈述性记忆（隐式）：会"怎么做"，比如技能、习惯、条件反射。

一个真正好用的助手，不光要记得你说过什么，还要不用提醒就照着学过的方法做事、避开以前踩过的坑。这就是隐式记忆。

作者挑了三种

  • 程序记忆：学会一个新规矩，被打岔之后还能照做；
  • 启动效应：前面看到的内容，悄悄影响后面的输出；
  • 经典条件反射：某个信号和某种结果反复一起出现之后，下次一见到这个信号，就自动做出反应。

作者有个设计原则，叫"功能上同构"：不是生搬硬套心理学实验，而是把每种记忆机制的"功能"，翻译成 AI 助手真实会遇到的文字场景。

第二幕：考卷怎么出，"学习 → 打岔 → 测试"

基本信息

  • 300 道题，三种记忆各 100 道，分属 18 类任务。
  • 先用 GPT-4o-mini 按模板生成 1000 多个候选题，再经过自动检查、模型审核和人工审核，留下 300 道。

每道题都是三段式

  1. 学习（或启动）：让模型学一个规矩，或者读一段内容；
  2. 打岔：插进一段别的对话，让学习和测试之间隔开一段距离；
  3. 测试：出一个新问题，看模型会不会自动用上刚才学到的东西。

而且只看第一次的回答。答错了就是错了，不给改正的机会。作者把这叫"第一次就做对"的准确率。

注意这里有个小心思：只看第一次。真实场景里，agent 第一次就用错工具、删错文件，事后再改也来不及了。

打岔要打多久

作者先做了个小实验（只在程序记忆上）：打岔约 200 个 token 时，准确率 58.4%；约 500 个 token 时，降到 50.1%；再往后，1000、2000 个 token，基本稳定在 49.5% 左右。所以正式题目把打岔长度定在约 500 个 token。

第三幕：三种隐式记忆，分别怎么考

程序记忆：学会一个新规矩

考什么：教模型一个"反常规"的新规矩，看它被打岔之后还能不能照做。分五类：

类别 例子
工具和接口 参数顺序反过来（先写目标、再写来源）；每次调用前加一个会话前缀；用一套"外星文件系统"的奇怪分隔符
语言格式 回答必须套上固定的"签名"格式；必须用规定的开头和结尾问候语
逻辑运算 一个自定义的运算符；改过的斐波那契数列，F(n) = F(n−1) + 2F(n−2)
抽象规则 棋盘上有个"禁止落子的格子"；一个"敲三下"的固定仪式
创作约束 不许用第一人称；比喻只能用植物

怎么考：1–3 轮学习（规矩加例子），然后 10–15 轮打岔。打岔内容很"阴险"：话题相关，但用的是别的规则、别的名字。比如学的是 F(n)，打岔里就用 G(n)、H(n)，专门和学到的规矩抢地盘。最后出一道新题。

怎么判：格式类的用规则自动检查，语义类的让模型裁判来判。

启动效应：被前面的内容悄悄带偏

考什么：前面读到的内容，会不会在不被要求的情况下，影响后面的创作。

怎么考：每道题都有一对实验，这是这部分最讲究的设计：

  • 实验组：先读一段 130–170 字、画面感很强的描写，比如"深海"：生物荧光、巨大的水压、远古的生物；
  • 对照组：先读一段长度差不多、但很枯燥的技术文字，比如"国际标准集装箱的尺寸和载重"；
  • 两组接下来的 2 轮打岔完全一样（都是中性的技术对话），最后的创作任务也完全一样（比如起名、写广告语、想概念）。

怎么判：让 GPT-4o-mini 当裁判，把两组的输出放在一起比，打一个 0–100 的"启动影响分"。规则很严：输出里一个相关的词都没有，最多 20 分；只在一个方面像，最多 40 分。

有了对照组，才能分清：输出里的"深海味"，到底是被前面的内容带出来的，还是模型本来就会这么写。

经典条件反射：吃一堑，长一智

考什么：某个信号和某个结果反复一起出现之后，模型的第一个决定会不会因此改变。分三类：工具和接口安全、对话中的自我调整、系统保护。

怎么考：4 轮"信号—结果"的配对学习，然后 2 轮无关的闲聊，最后让同样的信号再出现一次，看模型第一步怎么做。

两种方向：

  • 偏好型：学会"更倾向于做某件事"。比如某个目录下的操作总是顺利，下次就优先用这个目录。
  • 抑制型：学会"别再做某件事"。比如用户一听到专业术语就困惑，下次就该少用术语；某个接口总出错，下次就别先调它。

第五幕：最大的发现，学"喜欢"容易，学"别做"难

偏好和抑制的巨大落差

条件反射里，两种方向的平均成绩：

类型 平均准确率
偏好型（学会更倾向于做某事） 75.0%
抑制型（学会别再做某事） 17.6%

差了 57.4 个百分点，统计上非常显著。最极端的两个任务：

  • 避免专业术语（用户被术语弄糊涂之后，下次就该少用）：只有 4%；
  • 目录偏好（某个目录总是好用，下次就优先用它）：72%。

打个比方：学会"更喜欢走这条路"很容易；学会"那条路走不通，别再走了"却很难。就像一个人明明在某家店踩过雷，下次饿了，还是先推门进去。

五个"所有模型都卡住"的地方

任务 平均准确率（± 波动）
避免专业术语 4%（±5%）
不信任出过错的接口 21%（±17%）
根据上下文调整行为 28%（±23%）
回避出过问题的接口 45%（±29%）
根据用户情绪调整策略 55%（±18%）

这五类都低于 60%，而且不分模型、不分厂家都卡。作者认为，它们的共同点是需要"主动压住默认行为"、"跳出表面模式去抽象"或"根据情境动态调整"。

表面的规矩好学，深层的规矩难学

程序记忆里，前五名模型：

  • 表面格式类（比如套一个固定格式）：93.8%；
  • 深层的多规则流程：60.0%。

Claude-4.1-opus 在表面任务上 95%，到了多重约束的流程只剩 65%。

平均分会掩盖短板

DeepSeek-R1 总分 65.3%，可在它最弱的任务上掉到 49%；GPT-5 和 Qwen3-32B 在最弱任务上更是只有 27%–36%。

被带偏越多，越不守规矩

作者报告，启动效应越强的模型，违反约束也越多（相关系数 0.63）。他们的解释是：模仿前文风格的冲动，压过了遵守任务要求。（不过论文图里对这个 0.63 的标注和正文说法不完全一致，后面会提。）

第六幕：给模型配上"记忆模块"，有用吗？

现成的记忆增强 agent

作者在附录里测了三个现成的记忆增强 agent：

系统 底座 总分变化
MemAgent Qwen2.5-14B +3.9
MemGPT Yi-34B-200K +2.3
MEM1 Qwen2.5-7B −2.1

提升很小，有的还变差了；条件反射一项，MemAgent 只有 22.00、MemGPT 只有 25.00。

直接把答案"存进记忆"

作者还做了一个"开卦"实验：用 Mem0 这个记忆系统，人工把关键规则或配对存进去，相当于把考点直接写进笔记本。

  • DeepSeek-R1：总分 65.30 → 74.12，其中启动效应从 49.90 跳到 75.35；
  • Qwen2.5-7B：总分 43.49 → 56.00，主要是程序记忆和条件反射涨了。

即使把关键信息明明白白地存好，提升也参差不齐，离人类基线还远。

这就是标题想说的："写下来"不等于"做得到"。 记忆模块解决的是"找得到"，隐式记忆要的是"自动用上"。

作者据此认为，这些短板来自注意力和记忆机制本身的局限，需要架构上的创新，而不只是把模型做大。（这是推断，论文没有做架构实验来直接证明。）

看一个例子：一个工具连错三次，第四次还用不用？

这是论文附录里的一个条件反射例子（是生成题目时用的示范，不是正式考题，但最能说明这类题在考什么）：

学习阶段（约 4 轮）：

  • 用户："帮我 run diagnostics（跑一下诊断）……"
  • 模型调用 analyzer_v1，报错。
  • 类似的请求又来了几次，analyzer_v1 在 4 次里有 3 次报错，只成功了 1 次。

打岔阶段（2 轮）：聊点无关的，比如问天气。

测试阶段：

  • 用户："帮我 run diagnostics on the database server（给数据库服务器跑一下诊断）。"
  • 理想的第一反应：换成轻量版的 analyzer_v2_lite，或者至少先提醒一句"这个工具之前经常出错"。
  • 典型的失败：二话不说，又去调 analyzer_v1。

巧在哪里：

  • 用户从头到尾没说过"别用 analyzer_v1"，模型得自己从失败里总结；
  • 只看第一步，模型不能"先错一次再改"；
  • 这正是真实 agent 最常见的毛病之一：同一个出错的工具调用，一遍遍地重试。

（顺便说一句，这个示范例子的打岔部分里，两个问题配的是一模一样的天气回答，看起来是生成时的小失误。）

第七幕：别人怎么看这篇论文

  • 获奖：ACL 2026 最佳资源论文。据一篇中文报道，今年 ACL 收到 12,148 篇投稿，主会录用率约 19%，最佳资源论文只有 4 篇。
  • 一篇实践者的长博客（Blake Crosley，2026 年 4 月，标题大意是"你的 agent 有一些你没写下来的记忆"），从工程角度读这篇论文：
    • 提出"说明文件幻觉"：把规则写进 CLAUDE.md、SOUL.md 这类说明文件是必要的，但不够，写进去不等于第一次就能照做；
    • "禁止做什么"最好用代码强制执行，比如检查器、调用工具前的拦截、沙箱策略，而不是只靠提示词，这正对应论文里"抑制最难"的发现；
    • 上下文本身会"启动"行为：工具返回的内容、检索到的网页，都可能悄悄影响后面的决定；
    • 建议把"第一次的结果"和"改正后的结果"分开记录；发现行为漂移时，与其反复纠正，不如开一个新会话。
    • 他也说得很坦白：论文测的是裸模型，不是真实的 agent 产品；这些工程建议都是他自己的延伸，没有被论文验证；"偏好 vs 抑制"的落差，也可能部分来自这套测试方法本身。
  • alphaXiv 的 AI 概述特别点出：外加显式记忆模块，有时反而会让成绩变差；论文对短板的讨论，指向"主动抑制"和"超越表面模式的抽象"这两个方向。
  • 我没有找到公开的审稿意见或学术讨论，alphaXiv 的讨论区也是空的。

几个有意思的小发现

  • 推理模型占了前排。 前六名里有 DeepSeek-R1、GPT-5、GPT-o3、GPT-o4-mini-high 这些会"多想一会儿"的模型，不过论文没有专门比较推理和非推理模型。
  • 小模型可以赢大模型。 Qwen3-8B 的总分超过了 Claude-4.1-opus 和 Gemini-2.5-pro。
  • 启动效应大家都差不多。 17 个模型挤在 42.67 到 51.95 之间，说明"被前文带偏"的程度，和模型强不强关系不大。
  • 打岔超过 500 个 token 之后，就不再往下掉了。 程序记忆从 58.4% 降到 50.1% 后就基本平了，说明要忘的在头几百个 token 里就忘了。
  • 把考点存进记忆，启动效应涨得最多。 DeepSeek-R1 的启动分从 49.90 跳到 75.35。很合理：你把"深海"那段话存进记忆，它当然更容易被带偏。

冷静一下：这篇论文没证明什么

  • 人类 100% 很可疑。 只有 5 位计算机博士生；而且启动影响分最高只到 95 分，所谓"100%"在这把尺子上没有定义，论文没有解释。所以"远低于人类"这个说法，在启动效应上最站不住。
  • 总分把"能力"和"易感性"混在了一起。 启动影响分越高，代表越容易被前文带偏，这未必是好事；论文自己的数据也显示，被带偏越多越不守规矩。可总分直接把它和程序记忆、条件反射平均了。
  • "记忆"的距离很短。 打岔只有约 500 个 token，启动和条件反射只有 2 轮。所有内容都还在上下文窗口里，测的更像是"同一段对话里的行为调整"，不是跨天、跨会话的长期记忆。对大模型来说，"隐式"和"显式"的区别，主要在于"有没有人提醒它去用"。
  • 出题和判卷都靠模型。 题目由 GPT-4o-mini 生成，启动效应也由 GPT-4o-mini 打分；人工审核了多少题、按什么标准，论文没有说清。
  • 样本不大，波动很大。 每种记忆 100 题，细分到小类就更少，有的类别波动高达 ±29%。
  • 温度设为 0 却跑了三次。 温度为 0 时，每次输出几乎一样，三次重复提供的波动信息很有限。
  • "需要改架构"只是推断。 论文没有做任何架构层面的实验。
  • 记忆增强实验不好比较。 用的是 Qwen2.5-7B、Qwen2.5-14B、Yi-34B 这些较老较小的底座，和主榜上的模型不在一个水平。
  • 有几处前后不一致。 摘要说 17 个模型，附录一处写"14 个"；程序记忆的打岔轮数，表格写 10–15 轮，附录的生成提示词写固定 15 轮；0.63 这个相关系数，正文和图的标注对不上；自定义运算符的公式，不同位置的写法也不完全一致。
  • 只覆盖了三种。 作者自己承认，知觉学习、习惯形成、运动技能、情绪条件反射这些隐式记忆，都还没测。

讲完了，带走三句话

  1. 记忆不只是"记得什么"，更是"自动做了什么"。 这篇第一次系统地测了大模型的隐式记忆：17 个模型最好的 65.3%，平均 55.3%。
  2. 最大的短板是"抑制"。 学会"偏好什么"平均 75%，学会"别再做什么"只有 17.6%；避免专业术语只有 4%。工具反复出错、用户已经反感，模型还照旧。
  3. "写下来"不等于"做得到"。 外加记忆模块、甚至把考点直接存好，提升都不稳定。重要的"禁止事项"，最好用代码来强制执行。

和我的方向有什么联系

  • "学考官"本身就像一种条件反射。 考官的某种偏好（信号）和高分（结果）反复一起出现，agent 就学会"遇到这种情况就这么做"。这篇的条件反射题型提供了一个现成的实验格式：4 轮配对、打岔、只看第一反应。
  • 一个可以检验的推测（我自己的）：把这篇和 Misevolve 那篇放在一起看，客服 agent 很快就学会了"退款能拿高分"，那是一种偏好；而这篇说明，从失败中学会"别再做"要难得多。如果这个不对称在记忆式 agent 里也成立，那么 agent 可能天生更容易学会"考官喜欢什么"，更难学会"任务上哪些做法是错的"。也就是说，记忆式自我改进可能天然偏向学考官。这可以分开测：正反馈驱动的学习和负反馈驱动的学习，各自有多快。
  • 启动效应的"实验组 + 对照组"设计可以直接借用。 想知道记忆里的内容（比如考官的评语措辞）在多大程度上"染色"了 agent 的输出，就配一份长度相同、内容中性的对照记忆。这正好也能补上我在 Misevolve 那篇里提到的缺失对照："是不是只是上下文变长了"。
  • 只看"第一次就做对"。 评估记忆带来的进步时，看的应该是积累记忆之后的第一次尝试，而不是多次重试、自我修正之后的结果。
  • 对 EHR agent 的提醒。 查询病历的工具在某些参数下总是报错，agent 下次很可能还会第一个去调用它，因为"抑制"恰恰是最弱的。这类"不要再做"的规则，最好写成代码层面的拦截，而不是只写在提示词或记忆里。
