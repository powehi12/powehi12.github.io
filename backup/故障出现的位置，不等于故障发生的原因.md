# 术语速查

正文第一次出现时也会再解释一遍，这里先集中列出。

| 术语 | 通俗解释 |
|---|---|
| **检查点（checkpoint）** | 基准在一个任务里埋的评分点，逐个判"过"或"不过"。PhysicianBench 有 670 个 |
| **能力标签** | 每个检查点被事先归到四类之一：检索、推理、动作执行、文书 |
| **根因（root cause）** | 一次失败最初的起因。与"失败最后表现在哪个检查点"不是一回事 |
| **病灶（lesion）** | 我们人为制造的一处故障。因为是自己造的，所以它的根因是确定的 |
| **健康臂 / 病灶臂** | 对照组和实验组。同一个任务跑两遍，一遍不动，一遍注入病灶 |
| **rollout** | 跑一次任务的完整过程。因为 Agent 有随机性，同一配置要跑多次 |
| **注入点（task-root）** | 一个"任务 × 一处病灶"的组合。本轮共 18 个 |
| **噪声地板** | 什么都不改时结果本身的波动幅度。小于这个幅度的差异不算数 |
| **ITT** | 按分配的组别统计，不因中途出意外而剔除样本。医学试验的标准做法，避免挑样本造成偏差 |
| **Holm 校正** | 同时做多个检验时，把显著性标准调严，防止碰运气碰出"显著" |
| **共同主终点** | 事先说好的两个必须都达标的主要指标。只过一个就叫 MIXED |
| **等价带** | 事先划定的"可以认为没差别"的区间。落在带内才算恢复到原状 |
| **冻结 / 解盲** | 先把分析方法写死（冻结），再去看完整结果（解盲）。防止看到数据后再改算法 |
| **fail-closed** | 判不出来就算失败。本基准中 PARTIAL、异常都算不过 |

# 汇报摘要

## 问题

Agent 基准现在不只给系统打分，还给出诊断——"这个模型的主要短板是临床推理"。

这个诊断是怎么来的？给每个评分检查点贴一个能力标签，然后数各类别下失败了多少个，最多的那类就是瓶颈。

**但在长程任务里，一个上游错误会让下游一连串检查点跟着失败。** 于是一个根因被记成好几笔不同能力的账。本文检验这条记账规则。

## 核心主张（立场）

**检查点上的能力标签，说的是"这一步在检查什么"，不是"失败从哪儿来的"。** 我们看到的失败分布，是真实根因经过一层"放大与串味"之后的结果。在这层混合被证明可以忽略之前，"最弱能力"这个诊断不成立。

## 第一轮实验的位置

第一轮的目的是**证明这层混合确实存在**，并给出几个关键指标的首次估计。

**已达成**：主要指标通过——一处受控的环境故障平均额外造成 **0.833 个检查点失败**（95% 置信区间 [0.574, 1.148]，明显高于噪声地板 0.315，校正后 p = 0.0002）。更重要的是，这些失败**散落在多个能力类别上**：文书类的净增加是 0.222，置信区间不跨零——**而文书类检查点在这次干预中根本没被碰过，它们多出来的失败就是回声。**

**未达成**：分页缺陷那一臂没过门；"故障位置越靠前、波及越广"这条曲线没验证出来（分层设计有缺陷）；有一个比例指标因分母不可辨算不出来；核心的分列矩阵没冻结。这几项主要受限于本轮规模（只跑了 6/100 个任务）和三处可修正的设计问题。

# 一、引言：从打分到诊断

Agent 基准正在做一件比打分更强的事：它们开始下诊断。

成功率回答的是"Agent 有没有做成"；能力分解声称回答的是"它为什么没做成"。**后一句话的分量重得多**——它决定该改哪个组件、该选哪个模型、一个领域该把力气花在哪。

这类诊断的做法很简单：给每个检查点分配一个能力标签（检索、推理、动作执行、文书），然后在各类别内数失败个数，最多的那类就叫主要瓶颈。

这个做法隐含一个假设：**在推理检查点上看到失败，就等于推理有毛病。** 长程任务直接挑战这个假设——前面的动作决定了后面能拿到什么信息、环境处于什么状态，所以一个上游错误会让好几个下游检查点接连不过：

```
关键数据没进入 Agent 能看到的范围
          ↓
临床判断建立在残缺证据上
          ↓
动作计划跟着出偏差
          ↓
最终文书继承了这个偏差
```

**有一点必须马上说清楚，否则全文会被误读。** 这些下游失败不一定是评分错了。推理检查点可能确实没满足要求，文书可能确实不完整。**出错的是把它们当成"四条互相独立的能力证据"来数。** 换句话说：

> **基准记录的是故障在哪里显现，研究者推断的却是故障从哪里产生；在长程任务里，这两个量不是一回事。**

我们把同一个根因在下游留下的那些失败叫 **failure echoes（失败回声）**，把"一个根因被记成多笔账"这件事叫 **causal amplification（因果放大）**。

本文用一个数学模型把这个区分讲清楚，再提出一种**干预式审计**：人为制造一处来源明确、又能撤销的故障，观察它在下游造成了哪些检查点失败，从而估计"一个根因是怎么变成一堆能力标签的"。

我们需要这样一个环境：能在不动 Agent 的前提下操纵故障的**来源**，同时还能观察到它的下游**表现**。为此我们选了 PhysicianBench——一个可执行的长程 EHR 基准，检查点覆盖检索、推理、动作执行、文书四类（arXiv 2605.02240）。**我们的目标不是判某一篇论文的对错，而是检验这类诊断共同依赖的那个假设。**

## 1.1 本文处在哪一层

近期的评测审计工作已经填了两层，本文是第三层：

| 层级 | 问的是什么 | 代表工作 |
|---|---|---|
| 结果效度 | Agent 到底成没成功？ | *Benchmarking the Benchmarks*（2607.02577），审计了 4 个基准的 496 条轨迹 |
| 过程效度 | 这个分数是不是通过基准预期的路径拿到的？ | success provenance 类工作 |
| **诊断效度** | **失败之后，基准说的"为什么失败"站不站得住？** | **本文** |

前两层验证的是"任务成没成功"，或者是在评测那些专门做归因的模型。**没有人回头检验基准自己发布的那套能力标签，是不是真的指向了根因。**

# 二、失败表现不等于失败来源

## 2.1 两种被混在一起的标签

**表现标签**：这个检查点在检查什么。比如"有没有查到某项化验"、"临床判断对不对"、"动作有没有执行"、"文书里有没有写明"。

**来源标签**：这次失败最初是什么引起的。

举个例子。一个临床推理检查点没通过，至少有三种可能：

1. Agent 拿到了完整证据，但推理错了；
2. Agent 压根没拿到关键证据；
3. 上游工具返回了残缺或错误的信息。

**只有第一种能支持"推理能力有缺陷"，后两种不能。**

由此得到本文的核心措辞——它比"标签贴错了"精确得多，也更难被反驳：

> **检查点上的能力标签，是对"这一步要求什么"的语义标注，它本身并不自动说明失败从哪儿来。**

## 2.2 失败传播矩阵

现在把上面的话写成公式。

先定义一个数：

$$P_{ij} = \text{注入一个 } j \text{ 类根因，平均会在 } i \text{ 类检查点上造成几个失败}$$

**读法**：$j$ 是"我们制造的故障属于哪一类"，$i$ 是"失败最后记在哪一类账上"。比如 $P_{\text{文书},\text{检索}}$ 就是"一处检索故障，平均在文书类检查点上造成几个失败"。

把所有 $P_{ij}$ 排成一个方阵，就是**失败传播矩阵** $\mathbf P$：

- **对角线上的数**（$i = j$，比如"检索故障 → 检索失败"）：根因老老实实表现在自己的类别里；
- **对角线以外的数**（$i \neq j$，比如"检索故障 → 文书失败"）：串到别的类别去了，也就是**失败回声**。

有了它，就能写出本文的核心式子：

$$\mathbf y = \mathbf P\,\mathbf r + \boldsymbol\epsilon$$

**读法**（这是全文最关键的一个式子，逐项解释）：

- $\mathbf y$ —— **我们实际看到的**：四类能力下各失败了多少个检查点，也就是基准论文里那张直方图；
- $\mathbf r$ —— **我们真正想知道的**：四类能力实际各出了多少次根因；
- $\mathbf P$ —— 把 $\mathbf r$ 变成 $\mathbf y$ 的那层"放大与串味"；
- $\boldsymbol\epsilon$ —— 随机噪声。

**现有做法直接把 $\mathbf y$ 当 $\mathbf r$ 来读。** 这等于假设 $\mathbf P$ 是单位矩阵——即"一个根因只造成一个失败，而且绝不串到别的类别"。这个假设从来没被检验过。

由 $\mathbf P$ 可以定义三个指标，都是"看某一列"得到的：

$$N_j=\sum_i P_{ij} \qquad M_j=\big|\{i: P_{ij}>0\}\big| \qquad Q_j=\frac{P_{jj}}{\sum_i P_{ij}}$$

**读法**：

- $N_j$（**失败倍数**）：把第 $j$ 列所有数加起来。含义是"一个 $j$ 类根因总共造成几个失败"。$N = 1$ 表示一因一果，$N = 3$ 表示一个根因被记了三笔账。
- $M_j$（**类别跨度**）：数一数第 $j$ 列有几行不是零。含义是"一个根因波及了几个能力类别"，取值 1 到 4。
- $Q_j$（**诊断保真度**）：对角线上那个数，占整列总和的比例。含义是"这些失败里，有多大比例老实待在了自己类别里"。$Q$ 越接近 1，标签越可信。
- $1 - Q_j$（**串味比例**，off-origin spillover）：反过来，就是"跑到别的类别名下去了"的比例。

## 2.3 为什么"最弱能力"这个结论不成立

> **命题**：如果 $\mathbf P$ 未知、又不保证是对角阵，那么光看 $\mathbf y$ 就无法唯一确定 $\mathbf r$。因此"$\mathbf y$ 里哪一类最大"不等于"$\mathbf r$ 里哪一类最大"。

用大白话说：

> **失败最多的那个类别，可能是因为它根因最多，也可能只是因为它接住了从上游滚下来的错误最多。**

心理测量学里早就处理过类似问题：如果几道题共用材料或有先后依赖，就不能当成独立观测。**Agent 的情况更严重**——前面的动作会直接改变后面检查点面对的信息和环境，这是有明确方向的因果依赖，不只是统计相关。

# 三、什么时候能力诊断会出问题

## 3.1 三条结构前提 + 一条解释条件（预期）

要让失败传播真的扭曲诊断，需要同时满足：

- **P1**：基准有 checkpoint 级的能力标签；
- **P2**：同一任务内的检查点之间有因果依赖（前面影响后面）；
- **P3**：失败被独立计数，不做根因合并；
- **P4（解释条件）**：论文或下游工作把这些计数解读成能力瓶颈。

前三条决定基准**有没有失真的结构风险**，第四条决定这个风险有没有真的变成错误结论。

## 3.2 跨基准结构审计（预期）

预期这些条件在长程 Agent 基准中广泛成立，从而支撑结论的普遍性：

| Benchmark | 有能力标签 | 有依赖 | 独立计数 | 解读成瓶颈 | 诊断风险 |
|---|:---:|:---:|:---:|:---:|:---:|
| PhysicianBench (2605.02240) | ✓ | ✓ | ✓ | ✓ | High |
| ART (2601.08988) | ✓ | ✓ | ✓ | ✓ | High |
| VitaBench (2509.26490) | ✓ | ✓ | ✓ | ✓ | High |
| FHIR-AgentBench | ✓ | ✓ | ✓ | 待核 | 待定 |
| MedAgentBench | ✓ | ✓ | ✓ | 待核 | 待定 |
| Mem2ActBench (2601.19935) | ✓ | ✓ | ✓ | 待核 | 待定 |

### 【实际实验结果】更严格判据下的审计

最终锁定的审计用了比上表**严得多**的标准：P1 要求能力标签在**评分程序的输出里能直接读到**（而不是写在论文正文中），P2 要求依赖关系**能从源码证明**。该审计**没有评估上表的第四列**，所以不能直接拿来补上表。

|---|:---:|:---:|:---:|:---:|

**和预期的关系**：严判据下的结果低于预期，但有两点要说明——

（i）这个判据要求标签在**评分产物**里可读，而多数基准把能力归类写在论文正文或附录里，**这会让 P1 判成 no，但不等于它们实践上没做能力分解**。普遍性论证换成"论文层面的能力分解实践"这个口径重做即可。

（ii）本轮只能陈述这 4 个基准，**不能外推到全部 Agent 基准**。

**要分清**：PhysicianBench 上做的是因果测量；其他基准上做的是结构风险审计，不是因果验证。

# 四、干预式诊断审计

## 4.1 为什么必须人为制造故障

最自然的做法是：翻真实的失败记录，人工判断根因，再看标签对不对。

**这条路走不通。** 因为根因判定本身就有争议——"Agent 没查到某项化验"，你说是检索失败，别人说它是**不知道该查什么**，那属于工作流规划，而工作流规划恰好被归进临床推理。**你想用来当尺子的东西，本身是弯的。**

所以我们的做法是：**自己制造一处来源明确的故障。**

干预时保持不变的：Agent 的提示词、模型和解码参数、任务集合、评分规则和评分标准。**只改一个环境或工具机制。** 这样根因属于哪一类是设计时就定死的，不需要事后判断。

## 4.2 怎么算

对每一个检查点 $v$，算两个概率的差：

$$\Delta_v = \Pr(v \text{ 失败} \mid \text{有病灶}) - \Pr(v \text{ 失败} \mid \text{无病灶})$$

**读法**：同一个检查点，注入病灶时失败的概率，减去不注入时失败的概率。差出来的部分，就是这处病灶造成的。

再按检查点的标签把它们加起来：

$$\widehat P_{ij} = \sum_{\text{所有标签为 } i \text{ 的检查点 } v}\Delta_v$$

**读法**：把所有"标签是 $i$ 类"的检查点的增量加总，就得到"$j$ 类根因在 $i$ 类上造成了多少失败"的估计。

**为什么用概率差而不是直接比两次运行的失败清单**：Agent 有随机性，同一配置跑两次结果就不一样，单次对比分不清是干预造成的还是运气。所以必须跑多次、比概率。

## 4.3 因果可达范围（causal reach）

我们不用含义模糊的"注入深度"，而用 **causal reach**：某个注入点在任务依赖图里**能够影响到的下游检查点有多少个**。

预测是：

$$\text{causal reach 越大} \implies N \text{ 越大，串味比例越高}$$

**读法**：故障发生的位置越靠前、下游依赖它的步骤越多，它造成的失败就越多、波及的类别就越广。

由此得到本文最本质的机制结论：

$$\text{看到的失败数} = \text{根因发生次数} \times \text{因果可达范围}$$

**能力直方图把这两个量混在了一起，而现有解读只承认前一个。**

## 4.4 统计上要做的事（预期设计）

- **噪声地板**：什么都不改，重复跑 8–10 次，看结果本身波动多大。小于这个幅度的差异不算数。
- **可逆性**：注入 → 撤销 → 再注入三段，确认变化确实是干预造成的。
- **模型档位**：太强的模型失败点太少、没样本；太弱的到处失败、根因混在一起。

### 【实际实验结果】实际怎么跑的

| 项目 | 预期设计 | 实际执行 |
|---|---|---|
| 重复次数 | 同配置 8–10 次，并把检查点分成稳定/不稳定两层 | **每臂 3 次 rollout**（分页共 18 次/臂，合成注入共 54 次/臂），另加了 `control_prime`、`original_prime` 两个匹配对照 |
| 噪声怎么估 | 靠重复实验的经验波动 | 分页用精确噪声分布；合成注入的全局尺度用 10,000 次蒙特卡洛模拟；类别跨度指标逐格精确枚举 8 种可能 |
| 可逆性 | 注入→撤销→再注入的时间序列 | 改成**随机分配的四组**：对照、对照副本、故障、撤销后 |
| 模型 | 按档位原则选 | `deepseek-v4-flash`，推理强度 high |
| 换模型验证 | 暗含比较 | 未做 |

**关于模型的一点说明**：`deepseek-v4-flash` 在 high 推理强度下属于**较强档位**，不是弱模型。所以本轮测到的传播效应，**不能归因于"模型太差所以到处失败"**——恰恰相反，在一个较强的 Agent 上仍能测出稳定的跨类别失败增量，对本文主张是**更强**的证据。

**覆盖范围**：计划的 288 个运行全部完成并进入分析（实际跑了 292 次，4 次因技术原因作废）。正式结论覆盖 **6/100 个任务、49/670 个检查点**，共 2,352 条"过/不过"记录。**不能说成对全部 100 个任务的验证。**

**证据状态**是「看完整结果之前就把分析方法锁死」，不是外部正式预注册：锁定前只看到了前 48 次运行的总数（11 过、37 不过），没有按任务、组别、注入点或标签拆开，也没有据此改过设计。

# 五、在这个临床基准上估计失败传播

## 5.1 为什么选它

PhysicianBench 满足四个条件：长程的跨阶段临床工作流；检查点级能力标签（100 任务 / 670 检查点 / 四类）；真实可操作的环境（Docker 打包的 FHIR 服务器、14 个工具、9 类可直接操作的医疗数据资源）；能在不动 Agent 的前提下做可撤销的环境干预。

**它是一个特别透明的实例，用来观察一种更普遍的诊断实践**，不是一个"结论有误"的靶子。这个基准一方面根据类别份额推断临床推理是主要瓶颈，另一方面又在错误分析里写了文书类失败主要来自上游错误的级联——**这个张力本身就是本文所讲现象的直接体现。**

## 5.2 已完成的静态审计

在做任何干预之前，我们把这个基准的评分代码逐个检查点解析了一遍，得到三条结果。

**（a）能力类型和评分方式高度绑在一起。**

四类能力用 LLM 裁判打分的比例极不均衡：临床推理 344/356、文书 99/99，而动作执行只有 3/112。用统计学的关联强度指标（Cramér's V，取值 0 到 1，越接近 1 说明两个分类变量绑得越紧）测出来是 **0.836 到 0.921**，随机置换检验的 p 值为 1/100001。

**通俗地说**：能被程序确定性检查的部分，被命名为"检索"和"动作"；难以写成确定性判断的部分，主要被归进"推理"和"文书"。

**（b）能被机器复原判据的检查点，各类别相差约三百倍。**

| 能力类别 | 宽松口径 | 严格口径 |
|---|---:|---:|
| 动作执行 | 112/112 = 100% | 106/112 |
| 数据检索 | 101/103 = 98.1% | 46/103 |
| 临床推理 | 20/356 = 5.6% | 1/356 = 0.3% |
| 文书 | 0/99 = 0% | 0/99 |

**这张表直接决定了实验的边界**：只有检索和动作能确定性地建立"已知根因"，推理和文书不能。所以病灶只能注入在环境侧，**推理和文书是我们观察回声落在哪里的位置，不是注入的入口**。

**（c）换一种数法，"最弱能力"就翻转。**

原论文用的是份额（某类失败数 ÷ 总失败数）。改用条件失败率（某类失败数 ÷ 该类题量），排序变成：文书 1.245 > 动作执行 1.125 > 临床推理 0.949 > 数据检索 0.807。

**推理低于全表平均，而且在 12 个模型中的 11 个上，排第一的从临床推理变成了别的。**

份额法之所以偏袒推理，是因为推理类题量占了 53.1%——题多，失败自然多。

这三条合起来说明：**"最弱能力"这个结论对数法高度敏感，而且能力标签和"能不能被确定性评分"根本不独立。**

## 5.3 可用的注入入口

| 入口 | 属于哪类根因 | 机制 |
|---|---|---|
| 各搜索工具的翻页上限 `page_limit` | 检索 | 可逐个工具单独调，能做出剂量梯度 |
| ICD 编码匹配语义 | 检索 | 工具侧是精确匹配，评分侧是前缀匹配 |
| 工具返回截断阈值（默认 1 万字符） | 检索 | 调低等于让 Agent 看到的内容被切得更狠 |
| 屏蔽某个工具 | 检索 / 动作 | 影响范围最大的一类 |
| 阻断特定的数据写入 | 动作 | 用来估计传播矩阵的第二列 |

### 【实际实验结果】实际用了哪些

| 入口 | 状态 |
|---|---|
| 搜索工具翻页上限 | **已做**：72 次运行，四组为 加重 / 原样 / 原样副本 / 修复 |
| 屏蔽某个工具 | **已做**：18 个注入点，其中 12 个检索类位于前段和中段，6 个动作类位于后段 |
| ICD 匹配语义 | 未做 |
| 返回截断阈值 | 未做 |
| 阻断数据写入 | 未单独做；本轮的动作类根因来自"工具不可用"这一机制 |

## 5.4 观测能力的限制

**预期**：基准的裁判只有判 PASS 才算过，PARTIAL、FAIL 和调用异常一律算不过，而且**裁判结果不存盘**。所以要先打补丁，把每次裁判调用的输入输出存下来，才能解释传播路径。

### 【实际实验结果】实际能看到什么

跑出来的数据足以估计失败增量。**但为了保护临床数据，导出到本地分析的内容刻意不含**模型输出文本、裁判的判断理由、病历内容、完整轨迹、工作区、原始工具参数与返回值。

所以本轮能回答"失败计数有没有随受控根因改变"，但**给不出逐例的机制重建证据**——也无法从本地验证机制层存盘到底做了没有。

# 六、一因多果：主结果

## 6.1 只能估计部分列（预期）

由 §5.2(b)，只有检索和动作能干净地注入，所以**严格来说只估计了矩阵 $\mathbf P$ 的部分列**，不声称恢复了完整矩阵。

**这不削弱主结论**：只要发现一个明显的非对角元素，就足以否定"$\mathbf P$ 是单位矩阵"这个默认假设——而这正是现有能力分解隐含的前提。

## 6.2 主结果表（预期结构）

**表 6.1｜传播矩阵的估计列**（行 = 失败记在哪一类；列 = 我们注入的是哪一类根因）

| 记在哪一类 \ 注入的是哪一类 | 检索病灶 | 动作病灶 |
|---|---:|---:|
| 数据检索 | 〔·〕 | 〔·〕 |
| 临床推理 | 〔·〕 | 〔·〕 |
| 动作执行 | 〔·〕 | 〔·〕 |
| 文书 | 〔·〕 | 〔·〕 |
| **$N_j$ 失败倍数（列和）** | 〔·〕 | 〔·〕 |
| **$M_j$ 类别跨度（非零行数）** | 〔·〕 | 〔·〕 |
| **$Q_j$ 诊断保真度** | 〔·〕 | 〔·〕 |
| **$1-Q_j$ 串味比例** | 〔·〕 | 〔·〕 |

**对角线是"记对了"，对角线以外就是失败回声。**

**预期主结果句**：一处受控根因平均额外造成 $N$ 个检查点失败、波及 $M$ 个能力类别，其中 $1-Q$ 的比例落在了根因自己的类别之外。

### 【实际实验结果】

本轮**没有**冻结"按检索/动作分列"的两列矩阵。为避免看到数据后再补分析，表 6.1 保持空白，不作事后回填。正式输出的是 18 个注入点在四类标签上的平衡汇总。

**主要指标**

| 指标 | 估计值 | 95% 置信区间 | 判定 |
|---|---:|---:|---|
| 失败倍数 `N_ITT` | **0.833** | [0.574, 1.148] | 高于噪声地板 0.315；校正后 p = **0.0002**；**通过** |
| 类别跨度 `M_ITT` | 0.944（17/18） | [0.611, 1.278] | 72 个格子中有 17 格明显超过各自的噪声门 |
| 类别跨度（不设噪声门）`M_raw` | 1.389（25/18） | [1.167, 1.611] | 只要求该格增量为正 |

**怎么读这三行**：`N_ITT = 0.833` 的意思是——平均而言，注入一处环境故障，会额外造成 0.83 个检查点失败。这个数明显高于"什么都不改时的自然波动"（0.315），而且校正后仍然显著。

72 个格子（18 个注入点 × 4 个标签）中，**25 格为正、38 格为零、9 格为负**，其中 17 个正格超过噪声门。

换一种更保守的算法（只统计依赖图上确实位于注入点下游的检查点）得到 `N_ITT = 0.852`，区间 [0.593, 1.167]，**方向一致**。

**失败落在哪几类**

| 记在哪一类 | 净增加 | 95% 置信区间 | 超噪声的注入点数 / 18 |
|---|---:|---:|---:|
| 动作执行 | **0.315** | [0.241, 0.426] | 5 |
| 数据检索 | **0.278** | [0.148, 0.407] | 6 |
| 文书 | **0.222** | [0.111, 0.315] | 4 |
| 临床推理 | 0.019 | [-0.111, 0.167] | 2 |

**这张表最重要的一行是文书**：净增加 0.222，置信区间不跨零。**而文书类检查点在这次干预中根本没有被直接碰过**——我们改的是搜索工具的翻页上限和工具可用性，全在检索和动作侧。文书多出来的这些失败，就是从上游滚下来的**回声**。

**因此 §6.1 所述的主结论成立条件已被满足**：矩阵 $\mathbf P$ 存在明显的非对角元素，"它是单位矩阵"这个默认假设被否证。

**还缺什么**：
（i）这是对**表现标签**的汇总，没有按根因来源分列，所以传播矩阵本身仍然是空的；
（ii）72 个格子没有单独做多重检验；
（iii）临床推理的区间跨零，本轮 6 任务子集上没测到稳定的回声效应——该类别在冻结子集中的注入点覆盖较少（只有 2/18 格超噪声门），需要扩大样本后重估，**暂不下方向性结论**。

**一处口径差异要注意**：初稿里 $M_j$ 是"这一列有几行不是零"，而实际算的 `M_ITT` 是"经过逐格噪声门筛选、再按 18 个注入点平衡后的平均标签跨度"。`M_raw` 概念上更接近初稿，但仍不是列级统计量。**两个都不能直接填进表 6.1。**

## 6.3 预注册判据

| 串味比例 $1-Q$ | 结论 | 论文形态 |
|---|---|---|
| ≥ 30% | 非对角传播显著 | 按本设计，因果审计为主线 |
| 10–30% | 传播存在但幅度有限 | 收窄主张，以传播矩阵为主结果 |
| < 10% | 该基准的归因近似局部 | 转为正面校准证据 |

### 【实际实验结果】这个比例算不出来

实际冻结的分页版 $Q$ 定义是"非检索类的下降 ÷ 全部下降"，概念上接近串味比例，但**不是**表 6.1 里那个列对角占比。

问题出在分母：分页组的**总失败下降只有 0.111**，置信区间 [-0.167, 0.389]，跟零分不开。做 10,000 次重抽样时，有 **2,960 次（29.6%）分母不大于零**，远超冻结时定的 5% 上限。分母都可能是零或负数，比值自然没意义。

**正式状态：`Q = NA`（总下降不可辨）。** 代数上算出来的 2.0 不可解释，不报区间。

**上面三档判据本轮无法触发**——原因是**统计功效不足**（分页组每臂只有 18 次运行），而不是 $Q$ 的真实取值落在某一档。

# 七、传播与任务拓扑

## 7.1 预期

横轴是注入点的 causal reach（能影响到多少个下游检查点），纵轴分别画失败倍数、串味比例、类别跨度。**预期三条曲线都随 causal reach 单调上升。**

最有力的结果形式是：

> **同一类根因，仅仅因为在依赖图里的位置不同，就获得了不同的"能力失败权重"。**

如果这个单调关系成立，就证明了能力直方图把"根因发生次数"和"拓扑位置"两件事混在了一起。

## 7.2 【实际实验结果】未验证，降为描述性

冻结清单里的前段/中段/后段三层，**同时改变了工具身份、故障机制和失败机会**，三层之间不可比。所以这份分析在看完整结果之前就已经标记为"仅描述性"，不构成对 causal reach 的确认性检验。

| 层级 | 失败倍数（95% CI） | 类别跨度（95% CI） |
|---|---|---|
| 前段 | 0.389 [0.000, 0.722] | 0.500 [0.167, 0.833] |
| 中段 | **1.333** [0.778, 2.056] | **1.667** [1.167, 2.333] |
| 后段 | 0.778 [0.556, 1.056] | 0.667 [0.333, 1.000] |

两条都在中段达到峰值，点估计不是单调上升。任务内的秩相关系数汇总为 0.553 和 0.334（**方向为正**，但只能作描述）。

**和预期的关系**：本轮**没有验证**单调关系。但这不构成对预期的否证——**问题出在分层设计**：前中后三层同时变动了工具身份和故障机制，所以层间差异混合了"可达范围"和"机制不同"两个来源，分不开。正确做法是构造"除可达范围外其他条件都一样"的分层。**这是可修正的设计问题，应在第二轮重做。** 秩相关为正，与预期方向一致，可作为重做的先验依据。

# 八、生态学复现与稳健性

## 8.1 用真实存在的环境缺陷复现（预期）

静态审计发现了三处环境契约不一致，其中两处可以当作"天然病灶"：

**（i）翻页契约不一致**：7 个搜索工具的说明书告诉 Agent "不指定参数我默认翻 6 页"（Condition 类是 3 页），但代码实现里省略参数时只翻 2 页（Condition 只翻 1 页）。Agent 发出的查询完全正确、数据也确实在服务器上，是工具层把后面几页扣下了，还什么提示都没给。

**（ii）ICD 编码匹配语义不一致**：诊断搜索用的是**精确匹配**，不支持层级或前缀；而评分侧的辅助函数对 ICD 码做的是**前缀匹配**。两边语义不一样，而且说明书没告诉 Agent。

**预期实验形式**：三档剂量——加重（只翻 1 页）／原样／修复（与说明书一致）。如果多个能力类别的失败数随损伤剂量单调变化，这一节就承担了"这个现象不是我们合成注入造出来的假象"这个职责。

### 【实际实验结果】分页这一臂没过门

| 指标 | 估计值 | 95% 置信区间 | 噪声 / 校正 p | 结论 |
|---|---:|---:|---|---|
| 非检索类的下降 | 0.222 | [-0.056, 0.500] | 噪声 0.500；Holm p = 0.099 | 未通过 |
| 全部类别的下降 | 0.111 | [-0.167, 0.389] | 噪声 0.556；p = 0.293 | 不可辨 |
| 检索类的下降 | -0.111 | [-0.222, 0.000] | 噪声 0.278 | 方向不符预期 |
| 加重 − 原样 | -0.056 | [-0.444, 0.222] | Holm p = 0.706 | 未通过 |
| 原样 − 修复 | 0.111 | [-0.167, 0.389] | Holm p = 0.586 | 未通过 |

**冻结分类：单调性不获支持。** 因为两个共同主终点一个通过（合成注入的失败倍数）、一个未通过（分页的非检索下降），**总状态记为 MIXED**。

**和预期的关系**：分页这一臂本轮没能承担复现职责。三点说明——

（i）该臂每组只有 18 次运行，而分页的噪声地板高达 0.5 到 0.56，**信噪比结构性不足**；
（ii）非检索下降的点估计是 0.222，**方向与预期一致**，只是区间跨零；
（iii）这个缺陷的实际损伤强度可能比设计时假设的小——"说明书 6 页 vs 实现 2 页"的差距，对一个较强的 Agent 来说可以通过显式指定参数绕过去。

**结论是这个天然病灶的效应量小于预期，需要更大样本或更强的天然病灶（比如 ICD 语义那一处）来复现，而不是这个现象不存在。**

**这些缺陷在论文里的地位不变**：它们是**量具**，不是发现。**bug 是可以修的，"把互相依赖的检查点当独立证据分别计数"这条记账规则不是修 bug 能消除的。** 所以标题和摘要里不出现具体缺陷名称。

## 8.2 撤销病灶，看能不能恢复

**预期**：注入 → 撤销 → 再注入三段，报告标签恢复率。

### 【实际实验结果】部分恢复

实际用的是随机分配的四组（对照 / 对照副本 / 故障 / 撤销后），不是同一条轨迹上的三段。

- **恢复率 = 0.765**，95% 置信区间 [0.556, 0.932]。即撤销病灶后，约 77% 的失败增量消失了。
- **故障组 − 撤销组 = 0.722**，区间 [0.352, 1.000]，高于噪声 0.315，**改善这一关通过**。
- **撤销组 − 对照组 = 0.111**，区间 [-0.204, 0.426]，**没有完全落进等价带** [-0.315, +0.315]。等价带的意思是"落在这个范围内就可以认为跟原状没差别"——没完全落进去，说明撤销后还残留一点差异。

**正式分类：仅部分恢复。** 方向与预期一致，但不能写成"完全可逆"。

## 8.3 排除"评分方式造成的假象"

**预期**：

（a）**评分标准原子化**——现在的评分是"全对才算过"：一个检查点挂了 $k$ 条要求，差一条整题算失败，而且 PARTIAL 也算失败。如果每条要求被误判的概率是 $\varepsilon$，那么整题被误判的概率大约是 $1-(1-\varepsilon)^k$。**读法**：$k$ 越大，整题失败的概率越高——**这跟能力完全无关，纯粹是算术。** 而文书类的要求条数确实比推理类多。所以必须把观测差异拆成"单条误判 + 要求条数 + 全对才算过"三项，排除这个替代解释。

（b）**裁判误杀率**——把医师写的参考答案交给基准自带的裁判，看它会不会把满分答案判成失败，为主结果配一个误差棒。

（c）**不做换裁判实验**——这个位置已被既有工作占据。

### 【实际实验结果】这部分没执行

这一阶段保持"未执行"。现有 492 条评分标准的拆分只是机器自动切出来的候选；60 条人工复核表里的 3 个人工字段和备注，**填写率是 0/60**。

缺的前置条件包括：前瞻性冻结协议、来源可追溯且有授权的真实医师参考答案、临床复核者、独立方法复核者、第三方裁决者、抽样与预算规则、独立审批记录。

所以本轮**没有**单条误判率、没有医师参考答案的误杀率、没有人工确认的原子化结果。评分机制的静态计数可以保留；**要求条数只能当作机器拆分候选的描述性统计**（文书类中位数 4、均值 5.30、最长 26 条；推理类中位数 3），不构成人工确认的证据。

**这意味着"要求条数多 × 全对才算过"这个算术替代解释还没被排除**，需要第二轮补上。

# 九、新颖性边界

**已经被人占了的位置：**

- **任务级对错的有效性审计**——*Benchmarking the Benchmarks*（2607.02577）审计了 4 个工具调用基准的 496 条轨迹，提出"基准分数往往反映的是评分器的性质而非 Agent 的性质"。它停在**结果效度**这一层。
- **LLM 裁判可靠性与换裁判**——2607.08535。**所以本文不做换裁判实验。**
- **用故障注入生成归因金标签**——Who&When Pro（2607.09996）、AgenTracer（2509.03312）。**所以不主张"首次用故障注入研究失败归因"。区别在于：它们审计的对象是归因模型，本文审计的对象是基准自己的诊断系统。**
- **重新设计一个解耦基准**——*Delegation Intelligence in Deep Search*（2607.23524）。本文走审计路线，不重设计。
- **"查到了但没用上"这类失败模式**——Mem2ActBench（2601.19935）已覆盖。
- **评测失败模式的综述**——*Beyond the Leaderboard*（2607.05775）综述 27 篇 / 19 个基准。本文可视为对其中测量效度那一簇的一次定量实例化。

**还没被占的位置：**

上面这些验证的都是任务级对错，或者是在评测归因模型。**没有工作检验基准自己发布的能力标签，是不是真的指向了根因。**

# 十、局限

**（a）只干预环境侧根因。** Agent 遇到环境异常时可能察觉、重试、换个查法，级联被削弱；而它自己的推理错误无从察觉，级联可能更强。所以测出的失败倍数严格来说只适用于环境侧根因。

**（b）只估计部分列。** 推理和文书的可复原覆盖率是 5.6% 和 0%，没法确定性建立已知根因；而且本轮没冻结按来源分列的汇总，所以传播矩阵仍是空的。

**（c）因果测量只在一个基准上做。** 其他基准只做了结构风险审计。

**（d）传播依赖于模型。** 本轮只用了 `deepseek-v4-flash`，没做换模型验证。

**（e）样本规模有限。** 6/100 任务、49/670 检查点、18 个注入点，不能外推到全部任务。

**（f）拿不到机制层证据。** 安全导出不含轨迹、裁判理由和工具返回，做不了逐例重建。

**（g）替代解释没排除。** "要求条数多 × 全对才算过"的算术效应还没测。

**（h）标签同源性待确认。** 承载能力标签的那个文件是在基准 arXiv 首版之后约七周才加进去的，而且不被官方评分脚本使用，需要写信问原作者它和论文正文用的标签是不是同一套。

## 必须守住的措辞边界

- **不说"能力标签贴错了"**——准确说法是：标签可能正确描述了这一步在检查什么，但还没被验证为"失败根因"的标签。
- **不说"临床推理不是主要瓶颈"**——当前干预只能识别检索和动作来源的传播，足以证明"失败直方图不能被无条件当成根因直方图"，但不足以完整还原推理和文书类真实的错误数量。
- **不声称已估计完整传播矩阵。**
- **不把跨基准的静态表说成跨基准的因果验证。**

# 十一、贡献与下一步

## 11.1 贡献

**贡献一｜指出一个新的测量缺口。** 区分"这一步在检查什么"和"失败从哪来"，并为序贯 Agent 评测中的能力分解定义**诊断效度**。新意不在于"发现级联"（级联本身不新），而在于**把级联从一句定性提醒，变成能力诊断的测量模型**。

**贡献二｜给出干预式审计方法，并完成一次可复现的实例化。** 用人为故障去估计"已知来源 → 已发布能力标签"之间的响应关系；四组随机分配 + 匹配噪声 + 看完整结果前锁定分析 + 24/24 回归与 28/28 一致性验证。

**贡献三｜提出一组可复用的诊断校准指标，并给出首次估计。** 失败倍数已估计（0.833，校正后 p = 0.0002）；类别跨度已估计；串味比例和 causal reach 曲线待第二轮补足。

**贡献四｜改变报告规范。**

> 在"因果局部性"被确立之前，基准论文应该把能力类别计数报告为**失败表现的分布**，而不是根因能力缺陷的诊断。

具体建议：没做因果校准时，用"检查点失败分布"这个说法，避免直接写"主要能力瓶颈"；同时报告表现计数和根因聚类；发布检查点依赖图；对代表性的上游机制做可撤销的病灶测试；跨模型比较时报告"该模型条件下的传播"。

## 11.2 第二轮实验计划

本轮四项没达成，都对应可识别的设计或规模问题，不是主张本身被否证：

| 没达成的项 | 原因 | 怎么改 |
|---|---|---|
| causal reach 单调性 | **分层设计缺陷**——前中后三层同时变了工具身份和故障机制，层间不可比 | 重构分层，让层间除可达范围外其他条件一致 |
| 分页复现 | **信噪比不足**——每组 18 次对噪声地板 0.5+；且该缺陷效应量小于假设 | 扩大样本；补 ICD 语义臂作为效应量更大的天然病灶 |
| 串味比例算不出 | **功效不足**——分母（总下降）不可辨，29.6% 的重抽样分母 ≤ 0 | 随样本扩大自然改善；或改用分列口径直接估 |
| 分列传播矩阵 | **没冻结这项分析** | 第二轮预注册时直接冻结按来源分列的汇总 |

**执行顺序**：① 把冻结子集从 6 个任务扩到 20–25 个；② 冻结分列传播矩阵（论文核心图现在还是空的）；③ 重做 causal reach 分层；④ 补第二个模型；⑤ 补裁判与评分标准校准；⑥ 补 ICD 语义臂。
